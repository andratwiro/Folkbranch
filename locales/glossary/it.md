# Italiano (it): translation glossary

Read this before translating, and keep it up to date. Every translator and every reviewer works from it, so the same word means the same thing everywhere.

## Voice

- Address the reader as tu (informal), never Lei.
- Short, plain sentences. The app speaks to someone's grandmother as much as to a genealogist.
- Keep `{placeholders}`, «guillemets» and the names of products (GEDCOM, Folkbranch, Gramps) exactly as they are.

## Project terms

| English | Italiano | Note |
|---|---|---|
| family tree | albero genealogico | the chart of people and relationships, not a plant |
| person's card | scheda | one person's page (Spanish "ficha", Catalan "fitxa") |
| archive | archivio | the whole collection a family keeps in the app |
| relative | parente | a member of the family |
| event on the map | evento | a dated life event with a place (Spanish "hecho", Catalan "fet") |
| source | fonte | where a fact comes from |
| story | racconto | a recorded or written account told by someone |
| reader / editor / owner | lettore / editor / proprietario | the three roles |
| invitation link | link d’invito | how a relative joins |
| review | revisione | an edit waiting for the owner to accept |

## Kinship words

Fill this language's entry in `lib/kinship-words.ts`. In many languages a father's brother and a mother's brother are different words, and so are the grandparents and in-laws. A native reader must confirm them.
