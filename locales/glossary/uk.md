# Українська (uk): translation glossary

Read this before translating, and keep it up to date. Every translator and every reviewer works from it, so the same word means the same thing everywhere.

## Voice

- Address the reader as ти (informal), never ви; Ukrainian words, not Russian calques (« родина », « розповідь », not « семья »).
- Short, plain sentences. The app speaks to someone's grandmother as much as to a genealogist.
- Keep `{placeholders}`, «guillemets» and the names of products (GEDCOM, Folkbranch, Gramps) exactly as they are.

## Project terms

| English | Українська | Note |
|---|---|---|
| family tree | родинне дерево | the chart of people and relationships, not a plant |
| person's card | картка | one person's page (Spanish "ficha", Catalan "fitxa") |
| archive | архів | the whole collection a family keeps in the app |
| relative | родич | a member of the family |
| event on the map | подія | a dated life event with a place (Spanish "hecho", Catalan "fet") |
| source | джерело | where a fact comes from |
| story | розповідь | a recorded or written account told by someone |
| reader / editor / owner | читач / редактор / власник | the three roles |
| invitation link | посилання-запрошення | how a relative joins |
| review | перевірка | an edit waiting for the owner to accept |
