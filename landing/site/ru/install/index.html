Инструкция по установке

Как установить Folkbranch

Folkbranch — бесплатная программа для семейного древа, которую вы запускаете у себя. На Mac или Linux это одна команда; на сервере HTTPS настраивается сам; на Windows надёжный путь — Docker; а всё это может сделать за вас ваш ИИ. Выберите один способ ниже.

Прежде чем начать

Архив ставит и ведёт один человек в семье. Родные только открывают ссылку в браузере. Выберите один способ ниже; если не уверены, берите первый: он заодно загружает вымышленную демо-семью, которую можно посмотреть.

Mac или Linux: одна команда

curl -fsSL https://raw.githubusercontent.com/danarkhipov/folkbranch/main/install.sh | sh

Ни Docker, ни Node не нужны: свой Node команда приносит сама и сверяет его с опубликованными контрольными суммами. Она напишет ссылку. Откройте её, назовите семью и, если хотите сначала осмотреться, загрузите вымышленную демо-семью. Хотите сперва прочитать скрипт? install.sh короткий, а в релизах лежат архивы и их контрольные суммы.

  • Всё попадает в ~/folkbranch (другая папка — через --dir): приложение, ваш архив в data, настройки в .env и журнал.
  • Другой порт: ... | sh -s -- --port 8080. Приложение слушает только этот компьютер.
  • Без Docker оно не запускается вместе с компьютером. После перезагрузки выполните cd ~/folkbranch && ./folkbranch open.
  • Если Node уже есть, то же самое делает npx folkbranch; запустите его снова, чтобы открыть приложение.
  • Чтобы удалить, выполните ./folkbranch stop и удалите папку. Вместе с ней уйдёт архив, поэтому сначала скачайте копию.

Windows: через Docker

На Windows надёжный путь — Docker Desktop. Файл docker-compose.yml из репозитория запускает опубликованный образ с томом в /data:

  1. Установите Docker с плагином Compose.
  2. Скопируйте из репозитория docker-compose.yml и .env.example, а затем .env.example в .env.
  3. В .env укажите в BETTER_AUTH_URL адрес, по которому будут открывать архив, а в BETTER_AUTH_SECRET — длинное случайное значение.
  4. Выполните docker compose up -d.
  5. Откройте приложение и перейдите по ссылке для первого входа из docker compose logs folkbranch.

Том folkbranch-data хранит архив: docker compose down его сохраняет, а docker compose down -v удаляет. Есть и установщик для PowerShell, irm https://raw.githubusercontent.com/danarkhipov/folkbranch/main/install.ps1 | iex, но на настоящем компьютере с Windows его ещё не пробовали. Можно также попросить ИИ настроить Docker за вас.

Сервер со своим доменом

Любой Linux-сервер с systemd и 512 МБ памяти: Ubuntu 22.04 и новее, Debian 12 и новее, AlmaLinux, Rocky или Red Hat 9, Fedora, Amazon Linux 2023. Docker и домен не нужны:

curl -fsSL https://raw.githubusercontent.com/danarkhipov/folkbranch/main/install.sh | sudo sh -s -- --server

Команда напишет ссылку, по которой вы назовёте семью, например https://203.0.113.5/setup?code=.... Откройте порты 80 и 443 в панели хостинга, если у неё свой брандмауэр. Приложение и Caddy работают как службы, стартуют вместе с сервером, а HTTPS настраивается сам: сертификат Let’s Encrypt продлевается автоматически.

Свой домен. Направьте его DNS на сервер и запустите ту же команду с --domain family.example.com, сразу или позже. Архив останется, но ссылки, созданные раньше, перестанут работать, когда сменится адрес.

Уже есть nginx или другой веб-сервер? Добавьте --no-caddy вместе с доменом и направьте домен на 127.0.0.1:3000. Если на сервере уже есть Docker, --domain family.example.com без --server запустит образ вместе с Caddy.

Railway

Репозиторий готов для Railway: одна служба, том в /data и проверка работоспособности. Тариф Hobby начинается примерно с 5 долларов в месяц; смотрите страницу цен Railway. Понадобится Railway CLI.

railway login
railway init --name folkbranch
railway config apply
railway variable set --service folkbranch "BETTER_AUTH_SECRET=$(openssl rand -hex 32)"
railway domain --service folkbranch
railway up --service folkbranch
railway logs --service folkbranch

В журнале появится ссылка, по которой вы займёте пустой архив. Том в /data обязателен: без него приложение откажется запускаться, лишь бы не потерять данные. Держите одну реплику, потому что SQLite и фото лежат на одном томе. Render, Fly.io, VPS с Docker Compose и панели вроде Coolify описаны на странице DEPLOY.md (на английском).

Пусть установит ваш ИИ

Вставьте эту строку в Claude Code, Codex или Cursor:

Агент прочитает открытую инструкцию, спросит, ставить на этот компьютер или на сервер, установит, откроет архив и подключится сам. Перед всем, что требует пароля или денег, он остановится. В Claude Code можно ещё добавить плагин командами /plugin marketplace add danarkhipov/folkbranch и /plugin install folkbranch@folkbranch и попросить «Установи Folkbranch».

Копии и обновления

  • Ежедневная копия. Сервер сам копирует базу каждый день, а также перед каждым обновлением, которое её меняет. Эти копии лежат на том же диске.
  • Копия в другом месте. Скачайте полную копию в Настройки → Данные и резервные копии или выполните ./folkbranch backup и унесите файл с машины. С Docker Compose: docker compose exec folkbranch node folkbranch.mjs backup, затем docker compose cp folkbranch:/data/backups ./backups.
  • Обновление. Запустите команду установки ещё раз, при любом типе установки; для Docker Compose — docker compose pull && docker compose up -d. Настройки и данные сохраняются. Когда выходит новая версия, владелец видит уведомление, а при обычной установке на своём компьютере ещё и кнопку Обновить сейчас, которая сначала сохраняет проверенную копию базы.

Все подробности — в руководстве по самостоятельному размещению (на английском). Переезжаете из другой программы? Читайте, как импортировать GEDCOM; беспокоит, кто что увидит, — про приватность.

Вопросы

Работает ли Folkbranch на Windows?

На Windows надёжный путь — Docker. Установщик для PowerShell, install.ps1, при каждом выпуске собирается и запускается на сервере сборки с Windows, но на настоящем компьютере с Windows его ещё никто не пробовал. Установка одной строкой проверена на Mac и Linux.

Нужен ли сервер?

Нет. На своём компьютере он запускается одной командой и открывается в браузере. Сервер нужен, только если родные должны заходить в архив откуда угодно. Без него команда ./folkbranch share даёт приложению временный адрес в интернете.

Сколько памяти нужно?

Около 70 МБ; при семье в тысячу двадцать человек и нескольких смотрящих — около 130 МБ. Хватит Linux-сервера с 512 МБ памяти.

Как обновить Folkbranch?

Запустите команду установки ещё раз. Настройки и данные сохранятся, база обновится при запуске. Сначала сделайте копию.
