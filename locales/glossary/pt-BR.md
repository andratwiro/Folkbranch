# Português (Brasil) (pt-BR): translation glossary

Read this before translating, and keep it up to date. Every translator and every reviewer works from it, so the same word means the same thing everywhere.

## Voice

- Address the reader as você (informal, as a family member would say it); Brazilian spellings and vocabulary, never European Portuguese.
- Short, plain sentences. The app speaks to someone's grandmother as much as to a genealogist.
- Keep `{placeholders}`, «guillemets» and the names of products (GEDCOM, Folkbranch, Gramps) exactly as they are.

## Project terms

| English | Português (Brasil) | Note |
|---|---|---|
| family tree | árvore genealógica | the chart of people and relationships, not a plant |
| person's card | ficha | one person's page (Spanish "ficha", Catalan "fitxa") |
| archive | arquivo | the whole collection a family keeps in the app |
| relative | parente | a member of the family |
| event on the map | fato (a dated life event) | a dated life event with a place (Spanish "hecho", Catalan "fet") |
| source | fonte | where a fact comes from |
| story | relato | a recorded or written account told by someone |
| reader / editor / owner | leitor / editor / dono | the three roles |
| invitation link | link de convite | how a relative joins |
| review | revisão | an edit waiting for the owner to accept |
