Moving a tree

Import and export GEDCOM: bring your family tree in and take it out

Folkbranch reads GEDCOM 5.5.1 and 7.0, Gramps files, Excel, CSV and plain text, and writes GEDCOM 5.5.1 back out. You see what a file holds before anything changes, and one undo takes an import back. Here is what comes across, what does not, and how to export from the program you use now.

What you can bring in

Use the arrow button in the top bar, drop a file on the chart, or open Settings → Data and backups → Add people from a file. Folkbranch reads:

  • GEDCOM, versions 5.5.1 and 7.0.
  • Gramps files: .gramps, and Gramps XML saved as .xml, with people, marriages, children, events, notes, sources and places.
  • Excel (.xlsx), CSV or TSV and JSON, read in your browser.
  • Plain text in Folkbranch’s short text format, one line per person.

Import is deterministic: no AI model is involved. Before anything changes you get a preview of what the file holds, including how many names already exist in the archive, and one undo takes the whole import back.

How to export a GEDCOM file from your current program

Every program words this a little differently, but the idea is the same: find Export or Download in the tree’s menu or settings and choose GEDCOM.

  • Gramps: Family Trees → Export → GEDCOM.
  • webtrees: Control panel → Family trees → Export, as GEDCOM.
  • Ancestry, MyHeritage, Geni: each has an export to GEDCOM in its tree settings.
  • Other programs: look for the same option; either GEDCOM version Folkbranch reads is fine.

Then import the file as above. If you are still deciding between programs, see how Folkbranch compares.

What carries over

This is checked on files written the way Gramps 6 and webtrees 2.2 write them:

  • Names, with the patronymic split off, the surname from birth and other names.
  • Dates in any GEDCOM form: exact, about, between, before, after, and periods such as a residence from 1900 to 1910.
  • Birth, death and their places; baptism, burial, occupation, residence, education, religion, census, emigration and other events as facts.
  • Notes, including shared ones, as a biography page. Sources with their archive and sheet, and how sure each citation is.
  • Families, marriages, divorces, and adopted and foster children. A divorce is drawn on the chart as a union crossed out with two slashes, and a separation with one.
  • Godparents and witnesses, as a fact naming the person, and as participants of an event such as a baptism.
  • “No children” and “never married” marks, and the map points of places in files from Gramps, RootsMagic, Legacy, MacFamilyTree or webtrees.
  • People marked private in the file stay hidden from readers.

What does not carry over

  • Photos and other files. A GEDCOM file only names them. Drop the pictures together with the file, or upload them to each person afterwards. The preview says how many links to files it found.
  • Places as records, with their old names, and archives with an address, live only in Folkbranch and its full copy. GEDCOM carries the place name.
  • Research notes kept outside people and families, such as Gramps tasks or webtrees stories and news.

The preview lists any other part of the file it will not read, by its GEDCOM name, before you decide.

Taking your tree out again

Settings → Data and backups → Download the .ged file writes everyone with their sources and facts, as GEDCOM 5.5.1, so Gramps, webtrees and other programs can read it. Details worth knowing:

  • A child’s link is written as PEDI adopted or PEDI foster; a divorce as DIV, and a separation as an event of type Separation, since GEDCOM has no tag for it.
  • GEDCOM has no tag for a stepchild, so that kind comes back as a birth child in another program.
  • Export can leave out living people, and someone kept private is marked so in the file.
  • The GEDCOM export does not include pages and photos yet. A full copy of the archive, with pages and photos, is a separate download on the same screen.

Moving a spreadsheet or a list

An Excel or CSV table becomes the same text format, so duplicate search, questions about ambiguous names and undo work as for GEDCOM. Columns are recognised by their headings in English and Russian and can be corrected by hand. A relative in a cell can be given by name or by row number. Identical names inside one file count as one person, and the window warns you about it.

Questions

Which GEDCOM versions does Folkbranch support?

Import understands GEDCOM 5.5.1 and 7.0. Export writes 5.5.1.

Does a GEDCOM file include photos?

No. A GEDCOM file only names photos and other files. In Folkbranch you can drop the pictures together with the file, and each one is attached to the people it belongs to, by the file’s own links, by the person’s id in its name, or by name. Otherwise upload photos to each person afterwards.

Can I undo an import?

Yes. You see what the file holds before anything changes, and one undo takes the whole import back.

Can I move from Ancestry, MyHeritage or Gramps?

Yes. Export a GEDCOM file from the program and import it. Gramps files (.gramps and Gramps XML) can also be imported directly. Folkbranch can export GEDCOM again, so you are not locked in.
